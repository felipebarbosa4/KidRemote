# KR-004 — Implement local schema and prove RLS and gateway trust boundaries

## Goal

Prove household isolation before any production table exposure.

## Context

docs/product-specs/BACKEND.md is a normalized logical design and RLS matrix, not deployed SQL.

## Scope

Create local-only versioned migrations and SQL allow/deny fixtures for parent households/devices/policy/grants/receipts and private credentials/pairing/push/outbox/audit. Define typed transactional function boundaries and test privileged gateway predicates.

## Out of scope

Production table exposure/deployment, remote production reset, extra databases, final mobile features.

## Dependencies

KR-001, KR-002 See [backlog](../ISSUES.md).

## Technical constraints

Create local-only versioned migrations and SQL allow/deny fixtures for parent households/devices/policy/grants/receipts and private credentials/pairing/push/outbox/audit. Define typed transactional function boundaries and test privileged gateway predicates.
Follow linked ADRs and the repository task contract. No unapproved product assumptions or production gate bypass.

## Security/privacy

Service keys bypass RLS; verify scoped elevated transactions independently and lock down definer helpers.

## Acceptance criteria

- [ ] AC-1: Migrations build the model from empty local DB with keys, composite tenant FKs, uniqueness, numeric constraints and needed indexes.
- [ ] AC-2: All parent-exposed tables enable RLS with minimum grants in the same migration; private tables/functions have no anon/authenticated broad access.
- [ ] AC-3: A/HA/DA and B/HB/DB fixtures prove own access and deny foreign access for SELECT/write/join/RPC and membership self-promotion.
- [ ] AC-4: Tests use real client roles/auth claims rather than only service-role; no-policy/null-auth/removed-membership cases fail closed.
- [ ] AC-5: Device gateway contract derives target from credentials and has negative HTTP tests/stubs for foreign targets and parent privilege attempts.
- [ ] AC-6: Control transaction commits version, grant, command and outbox atomically; rollback leaves no partial grant.
- [ ] AC-7: Migration/reset instructions are explicitly local and all required checks run before any client exposure.

## Unit test plan

Payload bounds and domain-independent validation fixtures.

## Integration test plan

Supabase SQL/pgTAP tests plus HTTP gateway isolation tests; DB-01–04 and AUTH-01–06.

## Physical-device test plan

Not applicable to schema; child route integration uses synthetic credentials.

## Failure-injection test plan

Transaction rollback, duplicate ID, concurrent writes, forgotten grants/policies and stale membership JWT.

## Observability

SQL/HTTP test evidence and query plans; secrets redacted.

## Definition of done

Local migration and allow/deny suites pass; trust boundaries match docs; no production exposure.
Run relevant tests, record actual evidence, update source-of-truth docs/ADRs and list unrun checks.
Do not report completed merely because a plan exists.

## Done when

Local migration and allow/deny suites pass; trust boundaries match docs; no production exposure.
