# KR-003 dual-path Home safety gate

- **Goal:** Record the owner's prospective dual-path Home evidence decision and publish a tested runner-v12 qualification bundle that supports either one exercised physical Home action or a separately named control-unavailable path using an independently calibrated host `KEYCODE_HOME` stimulus.
- **Context:** Runner-v11 proved that the coarse Android navigation-mode setting does not establish whether a Home control is available under the restriction. Historical Samsung attempts remain independently INVALID or FAIL and are not reclassified, resumed, replaced or pooled. OD-39, ADR-0002 and the KR-003 physical/configuration qualification contracts are the existing authority to amend.
- **Constraints:** KR-003 only; no candidate Accessibility-generated Home action, navigation-mode or lock-credential change, root/device-owner assumption, screenshots, Accessibility nodes/text/content, launcher/package history, accounts, serials, raw ADB output, weakened UNKNOWN gate, physical execution, historical reclassification, sample pooling or KR-004 work. The independent fixture must prove the positive-control Home stimulus displaced it and must remain the primary non-candidate oracle during the restricted stimulus.
- **Done when:** Existing authoritative decision/contract text records both paths and their distinct PASS/FAIL/INVALID semantics; runner-v12 records control exercisability separately from navigation mode, positively calibrates exactly one host `KEYCODE_HOME` against fixture focus before relying on Path B, injects exactly one restricted stimulus for Path B, keeps Path B distinct from `HOME_ACTION_EXERCISED_AND_RESISTED`, fails closed on uncertainty, and preserves cleanup; regression coverage includes both navigation modes, unavailable/unknown control, physical resistance/escape, transport success/rejection/no-effect, restricted hold/focus/restriction outcomes, historical ingestion, and no resume/pooling; PowerShell 5.1/7, Node, JVM/Android/release-isolation, repository validation, diff checks and CI pass; one clean source commit and immutable bundle are published; Issue #3 and draft PR #16 are synchronized; execution stops before any device run.
