## Implemented evidence surface

The isolated harness has no Internet permission and declares only Usage Access and boot receipt plus the system-protected Accessibility service.
Its service configuration has `canRetrieveWindowContent=false`, `isAccessibilityTool=false`, and only `typeWindowStateChanged`.
Static validation rejects network/broad package/overlay/device-admin/camera/location/audio permissions and node/text/screenshot/gesture/global-action calls.
Pure unit cases cover eligible/non-eligible monotonic intervals, expiry, same-boot restoration, reboot-like clock rollback,
permission health/service-heartbeat freshness, safe/ordinary/unknown surface classification and p50/p95/max calculation.
