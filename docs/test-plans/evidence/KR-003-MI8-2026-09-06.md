## Hypothesis under investigation

An ordinary-app Accessibility event may call `showOverlay()`. Attaching the Accessibility overlay may then emit an event associated with the spike package or another surface classified `SAFE_SYSTEM`; that event would call `hideOverlay()`. The exposed ordinary app could then emit a new event and repeat the cycle.

Status: **UNPROVEN** until a sanitized trace captures or rejects this event/disposition/show-hide sequence on the Mi 8.

Instrumentation is limited to log tag `KidRemoteKR003` and records only `elapsedRealtime`, event type number, coarse identity class
(`OWN_PACKAGE`, `KNOWN_SAFE_SYSTEM`, `ORDINARY_APP`, or `MISSING`), current/next disposition, restriction flag, overlay attachment state,
and current/next adapter outcome. It does not record a package identifier, node/text/content, account, serial, or app history.
